Una página web simple es la opción más accesible

Para que una persona de una colonia pueda reportar ayuda, una página web es más práctica que una app. No necesita instalar nada, funciona desde el celular con navegador y puede compartirse por WhatsApp o un enlace corto.

Esta propuesta permite registrar solicitudes de doctor, transporte o medicina, y también generar un código para confirmar la entrega de medicamentos.
