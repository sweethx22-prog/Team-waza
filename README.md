# Team-waza

Este proyecto tiene como objetivo ayudar a personas que presentan dificultades para movilizarse, ya sea por edad, discapacidad, enfermedad o cualquier situación que limite su acceso a atención médica o apoyo básico. Su propósito principal es facilitar el registro de solicitudes de ayuda, como consultas médicas, traslados y entrega de medicamentos, para que las personas puedan recibir apoyo de manera más rápida y ordenada.

La plataforma está diseñada para funcionar como una herramienta sencilla y accesible que permite a los usuarios solicitar ayuda y a instituciones como el municipio, IMSS, ISSSTE o DIF organizar mejor los apoyos, coordinar traslados y dar seguimiento a las necesidades de la comunidad. De esta manera, el proyecto busca mejorar la atención social, fortalecer la respuesta institucional y acercar servicios de salud y bienestar a quienes más lo necesitan.
